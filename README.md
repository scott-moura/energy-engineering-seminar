# Energy Engineering Seminar — Fall 2026: Data Centers

Website for UC Berkeley's Energy Engineering Seminar (ENGIN 93 / CIVENG 298). One page listing the
semester's lectures along a circuit-trace "map". Each recorded lecture plays in an in-page video player.
See [WRD.md](WRD.md) for the full requirements.

## Updating lectures

Edit the Google Sheet **F26-Lineup-Data**. Keep the column headers as they are; the site matches columns by name.

| Column | Notes |
|--------|-------|
| Week, Date, Speaker, Speaker Title, Affiliation | Required. Write `Org \| Unit` in Affiliation to show two lines. |
| Title | A blank title shows as "Title TBA". |
| Photo URL | Public link to a headshot. The sync saves a copy in `images/speakers/`. |
| Video URL | Paste the YouTube link once the video is uploaded. The card then becomes playable. |

The page reads the sheet live, so edits show up on the next page load. The sync script saves a
snapshot of the sheet and downloads new photos:

```bash
npm run sync
```

If a photo can't be downloaded automatically, save it by hand as `images/speakers/<first-last>.jpg`.

## Local preview

```bash
npm run serve
```

Then open http://localhost:8000.

## Files

- `index.html`: the page. The lecture cards between the `LECTURES:START/END` markers are generated by the sync script.
- `assets/js/data.js`, `render.js`: sheet parsing and card templates, shared by the browser and the sync script
- `assets/js/main.js`: live refresh, circuit trace, video player, newsletter sign-up
- `scripts/sync-sheet.mjs`: sheet → `data/lectures.json`, photos, pre-rendered cards
